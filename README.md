## 🔨 What I've Built (Production)

> These projects live in company org accounts — described here for context.

### 🏟️ Sports Facility Management Platform — *Rugoria*
Full sports facility booking & management system — two Flutter apps sharing one backend.
- **Stack:** Flutter · Dart · Spring Boot (Java 17) · GraphQL · PostgreSQL · Firebase · Docker
- **Scope:** Player app + club admin portal, ELO-based matchmaking, real-time court booking, geofencing, analytics dashboard, 19-module GraphQL backend
- **Role:** Lead engineer — mobile architecture, backend API design, feature ownership end-to-end

### 🎧 Consumer Apps & AI Features — *GoldFinch Games*
Published Flutter apps for Android, Apple TV, and macOS, including AI-powered and real-time media features.
- **Stack:** Flutter · SwiftUI · Firebase · ML Kit · WebRTC · FFmpeg · ExoPlayer
- **Scope:** ASMR relaxation apps ($10K+ revenue in 3 months), AI-powered home décor app with image segmentation, real-time video casting with adaptive compression
- **Role:** Full stack app developer — architecture, features, App Store/Play Store releases

### 🌍 Service Marketplace — *Elite Service Search (Freelance, US Client)*
Flutter mobile app for a US home services marketplace.
- **Stack:** Flutter · Firebase · Stripe · Google Maps · Hive · LLM APIs
- **Scope:** 33,000+ locations, 50+ categories, Stripe KYC + wallet, OCR invoice scanning, AI chat assistant that helps users find services and take actions using LLM APIs
- **Role:** Freelance Flutter engineer — owned mobile build end-to-end for an international client
